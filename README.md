# Frameworks_Assignment
# CORD-19 Metadata Analysis & Streamlit App

This project is part of the **Frameworks Assignment**, where we explore the **CORD-19 dataset** (COVID-19 research papers metadata), perform basic analysis, and build a **Streamlit web app** to visualize insights.

---

## Features
- Load and clean the `metadata.csv` file
- Explore publication trends, top journals, and common words in paper titles
- Generate visualizations (`matplotlib`)
- Build an interactive Streamlit app to filter and explore results
- Upload results and code to GitHub
